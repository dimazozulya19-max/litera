# 📚 Litera

> **Your stories. Your library. Your journey.**

**Litera** is a modern reading platform designed to bring stories from around the world into one place.

Discover, read, track, and organize **books, manga, light novels, web novels, comics, and more** through a clean and personalized reading experience.

---

## ✨ About Litera

Litera aims to become more than just an online library.

The goal is to create a complete reading ecosystem where users can:

- 📖 Discover new books, manga, light novels, and other literature
- 🔎 Search and explore works from around the world
- ❤️ Build a personal library
- 📊 Track reading progress
- ⭐ Rate and review titles
- 📝 Create reading lists
- 🎯 Set reading goals
- 📈 View personal reading statistics
- 🔖 Save bookmarks and reading progress
- 👥 Discover what other readers are enjoying

The platform will focus on a **fast, clean, modern, and distraction-free experience**.

---

## 🌍 Content

Litera is planned to support different types of literature from around the world:

- Books

- Comics

- Other forms of digital literature

## 🚀 Project Status

> 🟡 **Early Development**

Litera is currently in **Phase 1 — Foundation**.

The initial Next.js application scaffold, core routes, and shared navigation are
complete. The design system, database structure, APIs, and core functionality
will be added incrementally to keep the project focused and maintainable.

## 🛠️ Technology

The foundation currently uses:

- **Framework:** Next.js (App Router)
- **Frontend:** React / TypeScript
- **Styling:** Tailwind CSS
- **Typography:** Manrope
- **Package manager:** pnpm

Planned technologies:

- **Backend:** To be determined
- **Database:** PostgreSQL
- **Authentication:** To be determined
- **Deployment:** Vercel
- **Storage:** To be determined

The stack may change as Litera evolves.

### Local Development

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

Useful checks:

```bash
pnpm lint
pnpm build
```
